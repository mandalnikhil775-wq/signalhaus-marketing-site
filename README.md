# Signalhaus — SaaS marketing site

A responsive marketing website and interactive product preview for **Signalhaus**, a fictional business analytics platform. Built as a portfolio project with semantic HTML, custom CSS, and vanilla JavaScript.

> All company names, customer quotes, statistics, prices, and dashboard metrics are illustrative sample content. The page does not connect to a real analytics service.

## Preview

Open `index.html` in a modern browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. No build step, package install, or API key required. Google Fonts are optional; system fallbacks are included.

## Features

- Responsive landing page with mobile navigation
- Interactive dashboard range control and monthly/yearly pricing toggle
- Accessible FAQ accordions, focus states, and button labels
- Product feature storytelling, pricing tiers, testimonials, and conversion CTAs
- Search and social sharing metadata
- No framework or runtime dependencies

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript

## Project structure

```text
index.html   Page content and metadata
styles.css   Responsive layout, visual system, and components
script.js    Navigation and interactive controls
```

## Deploy

The project is static and can be hosted on GitHub Pages, Netlify, or Cloudflare Pages. For GitHub Pages, push the project folder to a repository and select the branch and root folder in **Settings → Pages**.
